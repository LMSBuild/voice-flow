Voice Flow

Talk, and it types for you.

Hold a key, say what you want, let go. Your words appear wherever your cursor is. It runs 100% on your computer: private, offline, no subscription. For Windows 10 and 11.

Install it (about 5 minutes)

1. Right-click the zip file you downloaded → Extract All → Extract. (It won't work from inside the zip.)
2. In the extracted folder, double-click Install Voice Flow.bat.
If a blue box says "Windows protected your PC": click More info → Run anyway. It's safe. It's just a small setup file that isn't registered with Microsoft.
3. Make it yours. It asks three quick questions:
• Name: e.g. "Smith Plumbing Flow"
• Logo: pick your logo file (PNG or JPG; square works best), or click No to skip
• Words: names it should always spell right (business, team, products, suburbs), or leave blank
Want a different name or logo later? Just run it again.
The app opens. Follow its steps. If it asks which model to use, pick Parakeet V3. It downloads once, which takes about a minute and needs internet.
Try it. Click into any text box, hold Ctrl + Space, say a sentence, and let go. If Windows asks to use the microphone, click Yes.

How to use it

Anywhere you can type (email, Teams, Word, browser), hold Ctrl + Space, talk, then let go. It's in your Start menu and on your desktop, and it starts by itself when you turn on your computer.

Built on Handy, the open-source dictation app (MIT licence, github.com/cjpais/Handy).
